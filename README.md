QUADRO KANBAN - RESTRIÇÃO DE DEPENDÊNCIA

SOBRE O PROJETO

O projeto consiste no desenvolvimento de um quadro kanban para organizar e acompanhar tarefas de uma maneira simples e prática.
Como base para a ideia, utilizamos a criação de um sistema de controle de estoque para uma lojinha, pensando em como organizar as
atividades necessárias para desenvolver esse tipo de sistema.

COMO FUNCIONA

O quadro é dividido em três colunas: A fazer, Fazendo e Feito. Cada coluna representa uma etapa do desenvolvimento das atividades.
É possível criar cartões com tarefas, adicionar checklists para acompanhar o que já foi realizado e também definir dependências entre
as atividades, ou seja, algumas tarefas precisam ser concluídas antes que outras possam avançar.

TECNOLOGIAS UTILIZADAS

Utilizamos três tecnologias para executar essa atividade:
HTML
CSS
JavaScript.

OBJETIVO DO PROJETO

A ideia foi desenvolver uma ferramenta que ajudasse na organização das tarefas, colocando em prática os conhecimentos que estamos adquirindo
no curso de Análise e Desenvolvimento de Sistemas, principalmente na parte de desenvolvimento Web e lógica de programação.
